# دعوة خطوبة حسين غسان العبدالله

موقع ثابت (HTML / CSS / JavaScript) لبطاقة دعوة الخطوبة، مبني على تصميم البطاقة الأصلية.

## المحتوى
- `index.html` — صفحة الدعوة (عربي، RTL)
- `style.css` — التنسيق والألوان المستوحاة من البطاقة
- `script.js` — العدّاد التنازلي، إضافة المناسبة إلى التقويم (ملف ICS)، ورابط المشاركة عبر واتساب
- `assets/` — صورة البطاقة الأصلية والزخارف المقتطعة منها

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>.

## النشر
الموقع ثابت بالكامل ويمكن نشره على GitHub Pages أو Netlify أو Vercel بدون أي إعدادات.

## المزايا
- مظروف مختوم يُفتح بلمسة ثم تخرج منه البطاقة
- بتلات متساقطة، ميلان البطاقة مع المؤشر، وظهور متدرج للعناصر
- التاريخ الهجري يُحسب تلقائياً بجانب الميلادي
- عدّاد تنازلي بأرقام متقلّبة
- خريطة مضمّنة عند الطلب + فتح في خرائط Google
- إضافة إلى تقويم Google أو ملف ICS (Apple / Outlook) مع تذكير قبل يوم
- مشاركة عبر واتساب، مشاركة النظام، ونسخ الرابط
- تأكيد الحضور عبر واتساب (اختياري)
- شريط أزرار سريع يظهر على الجوال عند التمرير

## تعديل البيانات
كل الإعدادات في أعلى `script.js` داخل الكائن `CONFIG`:
- `start`: موعد المناسبة (للعدّاد والتقويم)
- `mapQuery`: ما يُبحث عنه في خرائط Google
- `rsvpPhone`: رقم واتساب بالصيغة الدولية بدون `+` لتفعيل قسم تأكيد الحضور (يبقى القسم مخفياً إن تُرك فارغاً)

النصوص الظاهرة (الآية، نص الدعوة، التاريخ، المكان) في `index.html`.

## الاستضافة
يُنشر الموقع تلقائياً على GitHub Pages عبر `.github/workflows/deploy-pages.yml` عند كل دفع (push) إلى الفرع الرئيسي.
